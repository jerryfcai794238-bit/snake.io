# 貪食蛇音樂音效需求

音樂與音效需依表格 ID 命名並輸出 WAV 或 OGG；需要循環播放的音樂或環境音，需在檔名或備註中標明 Loop。

### 1 音樂清單

| ID | 音樂名稱 | 使用場景 | 風格描述 | 長度 |
| :--- | :--- | :--- | :--- | :--- |
| BGM-01 | Main Theme | 遊戲大廳 / 開頭動畫 | 輕快卡通，木箱鼓 + 合成器。 | 約 2:00 |
| BGM-02 | Loading BGM | 配對等待 / Loading | 節奏偏緩，可循環。 | 約 1:30 |
| BGM-03 | Ingame BGM | 對局戰鬥中 | 卡通 Battle Pop，支援動態強弱。 | 約 3:00 |
| BGM-04 | Victory Fanfare | 結算第一名畫面 | 嘹亮但不過度厚重。 | 約 0:08 |
| BGM-05 | Defeat Sting | 結算非第一名畫面 | 短促幽默、滑稽低音。 | 約 0:03 |

### 3 動態混音規則

| 優先級 | 觸發條件 | BGM 處理 | SFX 處理 |
| :---: | :--- | :--- | :--- |
| 1 | 衝刺啟動 | Band-pass 升頻，音量微增。 | `Dash_Start` 高優先級。 |
| 2 | 進入減速狀態 | Low-pass Filter，音量降低。 | 降低 `Move_Loop`。 |
| 3 | 擊殺或截斷事件 | BGM 短暫讓位。 | `Kill_Impact` 或 `Cut_Success` 搶占播放。 |
| 4 | 對局剩餘時間 < 30s | 切入緊張段落。 | 倒數滴答。 |
| 5 | 玩家死亡 | BGM 短暫壓低。 | `Death_Hit` 與 `Death_Shatter` 優先。 |
