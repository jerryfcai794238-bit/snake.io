# 《泡泡龍》美術需求 GPT 版

**用途**：提供給 GPT 生成概念圖、UI 示意圖、場景氛圍圖、icon 草圖與介面構圖參考。  
**對齊目標**：手機平台、直版畫面、泡泡龍玩法、單人關卡 + 雙人對戰。

---

## 1. 美術總方向

### 1.1 視覺定位

* 類型：休閒、明亮、可愛、清楚辨識
* 風格：卡通化、色彩飽和、適合手機直版遊玩
* 關鍵字：
  * 泡泡感
  * 輕快
  * 海邊 / 樂園 / 冒險感
  * 盤面清楚
  * 角色可愛
  * 操作區域乾淨

### 1.2 整體美術原則

* 盤面是主角，所有 UI 不可壓過盤面辨識。
* 泡泡顏色要高度區分，避免同色混淆。
* 直版手機構圖要保留上方資訊、中央盤面、下方操作區。
* 單人模式與雙人對戰可用不同配色或氛圍區分。
* 概念圖要看起來像正式手機遊戲，而不是純示意草圖。

### 1.3 色彩建議

* 主色：海藍、天空藍、亮白
* 輔色：粉、黃、綠、橘、紫
* 警示色：紅、橘紅
* UI 底色建議：
  * 半透明深色面板
  * 或柔和亮色面板
* 盤面泡泡建議：
  * 5 色以上
  * 每個色系亮度與邊框不同

## 2. 共通元件需求

### 2.1 泡泡元件

* 泡泡要有玻璃感或亮面高光。
* 每顆泡泡需有：
  * 外圈輪廓
  * 內部漸層
  * 高光反射
  * 微小立體感
* 顏色版本：
  * 紅泡泡
  * 黃泡泡
  * 綠泡泡
  * 藍泡泡
  * 粉泡泡

### 2.2 特殊泡泡元件

* 爆炸泡泡：
  * 中心有爆裂符號
  * 外圈可帶火花或閃光
* 彩虹泡泡：
  * 多色漸層或虹彩反射
* 穿透泡泡：
  * 有箭頭、穿透線條或能量光束感
* 冰凍泡泡：
  * 帶冰晶、霜紋、淡藍白色調
* 其他特殊泡泡若有新增，需能一眼看懂功能。

### 2.3 發射器元件

* 位於畫面底部中央。
* 外觀需像泡泡炮、泡泡槍、發射台或機械砲口。
* 需要有：
  * 發射口
  * 泡泡待機槽
  * 切換槽
  * 瞄準方向感

### 2.4 UI 共通元件

* 標題字
* 返回按鈕
* 開始按鈕
* 模式按鈕
* 星級圖示
* 分數字體
* 倒數時間圖示
* 步數圖示
* 提示視窗
* 結算視窗

  * 排行

## 5. 給 GPT 生成概念圖的使用方式

### 5.1 單張圖輸入格式

你可以直接這樣丟：

* `請畫《泡泡龍》遊戲大廳，手機直版，卡通風格，海邊背景，主打單人關卡與雙人對戰，畫面要有大 Logo、三個大按鈕與可愛泡泡感`

### 5.2 各 UI 推薦描述

* 大廳：品牌感、明亮、模式入口明確
* 單人地圖：章節感、漂浮關卡節點、星級
* 局中：盤面清晰、操作區乾淨、泡泡顏色鮮明
* 對戰中：左右對抗、壓力感、分數比較
* 結算：勝負明確、獎勵明顯、視覺有成就感

### 5.3 通用風格關鍵詞

* colorful
* cute
* polished mobile game UI
* vertical screen
* bubble shooter
* readable interface
* casual adventure
* ocean theme

## 6. 驗收原則

### 6.1 概念圖驗收重點

* 一眼看得出是泡泡龍遊戲。
* 一眼看得出是手機直版。
* 一眼看得出單人與對戰是兩個不同模式。
* 盤面區要明顯、操作區要清楚、UI 不可太擠。
* 角色與背景不能搶走泡泡盤面的視線。

### 6.2 不要畫成

* 太空泛的休閒遊戲
* 太複雜的 UI
* 盤面看不清楚的畫面
* 太像橫版或 PC 遊戲的畫面
