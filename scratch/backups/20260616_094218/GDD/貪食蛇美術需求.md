# 貪食蛇美術需求

版本：v15.0  
用途：提供外包美術、UI、Icon、特效、音效製作依據。  
主規格來源：[貪食蛇GDD.md](貪食蛇GDD.md)

---

## 1. 文件目的

本文件專注於「要畫什麼、畫在哪裡、有哪些狀態、按鈕與圖示如何表現」。  
主 GDD 負責玩法規則，本文件負責外包可執行的美術與音效需求。

交付時請注意：

- UI 需要依照參考圖拆分區塊、按鈕與狀態。
- Icon 需要能在小尺寸下辨識用途。
- 特效需要明確區分觸發時機、持續時間與玩家感受。
- 不製作獨立貨幣圖示需求；貨幣只作為 UI 文字或平台公版素材顯示。

## 5. 音樂與音效需求

### 5.1 音樂清單

| 音樂名稱 | 使用場景 | 風格描述 | 長度 |
| :--- | :--- | :--- | :--- |
| Main Theme | 遊戲大廳 / 開頭動畫 | 輕快卡通，木箱鼓 + 合成器 | 2:00 |
| Loading BGM | 配對等待 / Loading | 節奏偏緩，可循環 | 1:30 |

### 5.3 動態混音規則

| 優先級 | 觸發條件 | BGM 處理 | SFX 處理 |
| :---: | :--- | :--- | :--- |
| 1 | 衝刺啟動 | Band-pass 升頻，音量微增 | `Dash_Start` 高優先級。 |
| 2 | 進入減速狀態 | Low-pass Filter，音量降低 | 降低 `Move_Loop`。 |
| 3 | 擊殺或截斷事件 | BGM 短暫讓位 | `Kill_Impact` 或 `Cut_Success` 搶占播放。 |
| 4 | 對局剩餘時間 < 30s | 切入緊張段落 | 倒數滴答。 |
| 5 | 玩家死亡 | BGM 短暫壓低 | `Death_Hit` 與 `Death_Shatter` 優先。 |

### 5.4 不製作項目

- 不製作語音包。
- 不製作結算 SSS 評價專用 SE。
- 配對成功不使用歡呼聲。
- 敵方死亡不播放哀傷音。
