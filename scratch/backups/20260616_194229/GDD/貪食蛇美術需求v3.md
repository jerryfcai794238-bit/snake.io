# 貪食蛇美術需求

版本：v3  
用途：提供外包美術、UI、Icon、造型、貼圖、特效、音效製作依據。  
主規格來源：[貪食蛇GDD.md](貪食蛇GDD.md)

---

## 1. 文件目的

本文件專注於「要畫什麼、畫在哪裡、有哪些狀態、如何驗收」。  
主 GDD 負責玩法規則，本文件負責外包可執行的美術與音效需求。

交付原則：

- 所有 UI 都要拆成可獨立發包、估時、驗收的需求項目。
- 每個畫面中的按鈕、卡片、狀態、Popup、列表、輸入框，只要需要獨立設計或繪製，就拆成獨立需求。
- 若屬於現有遊戲規則或平台公版素材，不另開立美術需求，僅在備註標明。
- Icon 需在小尺寸下可辨識用途。
- 特效需明確定義觸發時機、持續時間、玩家感受與循環方式。
- 不製作獨立貨幣 Icon 需求；貨幣只作為 UI 文字或平台公版素材顯示。

### 8.3 動態混音規則

| 優先級 | 觸發條件 | BGM 處理 | SFX 處理 |
| :---: | :--- | :--- | :--- |
| 1 | 衝刺啟動 | Band-pass 升頻，音量微增。 | `Dash_Start` 高優先級。 |
| 2 | 進入減速狀態 | Low-pass Filter，音量降低。 | 降低 `Move_Loop`。 |
| 3 | 擊殺或截斷事件 | BGM 短暫讓位。 | `Kill_Impact` 或 `Cut_Success` 搶占播放。 |
| 4 | 對局剩餘時間 < 30s | 切入緊張段落。 | 倒數滴答。 |
| 5 | 玩家死亡 | BGM 短暫壓低。 | `Death_Hit` 與 `Death_Shatter` 優先。 |

### 8.4 不製作項目

- 不製作語音包。
- 不製作結算 SSS 評價專用 SE。
- 配對成功不使用歡呼聲。
- 敵方死亡不播放哀傷音。
