## 1. 文件目的

本文件專注於「要畫什麼、畫在哪裡、有哪些狀態、如何驗收」。  
主 GDD 負責玩法規則，本文件負責外包可執行的美術與音效需求。
由美術決定實際風格和把控品質。

交付原則：

- 所有 UI 都要拆成可獨立發包、估時、驗收的需求項目。
- 每個畫面中的按鈕、卡片、狀態、Popup、列表、輸入框，只要需要獨立設計或繪製，就拆成獨立需求。
- 若屬於現有遊戲規則或平台公版素材，不另開立美術需求，僅在備註標明。
- Icon 需在小尺寸下可辨識用途。
- 特效需明確定義觸發時機、持續時間、玩家感受與循環方式。
- 不製作獨立貨幣 Icon 需求；貨幣只作為 UI 文字或平台公版素材顯示。

### 1.1 外包交付格式與命名規則

| 類型 | 輸出格式 | 命名規則 | 備註 |
| :--- | :--- | :--- | :--- |
| UI 元件 / Icon | PNG 透明底，並保留可編輯原始檔 | 檔名不可包含中文；使用需求 ID + 英文名稱 + 狀態，例如 `UI-HUD-02_dash_button_normal` | 若同一元件有 Normal / Pressed / Disabled 等狀態，需分檔輸出。 |
| 地圖背景 / 地圖物件 | PNG，並保留可編輯原始檔 | 檔名不可包含中文；使用需求 ID + 英文名稱，例如 `MapObj-01_river_tile` | 河流、岩石與裝飾物件需能與背景分離，便於程式擺放或調整。 |
| 造型 / 貼圖 | PNG 透明底，並保留可編輯原始檔 | 檔名不可包含中文；使用表格 ID + 英文部位，例如 `Skin-001_classic_head`、`Emote-B01_happy` | 蛇頭、蛇身節點需分開輸出。 |
| 動態效果 | PNG 序列圖或可由引擎重建的特效素材 | 檔名不可包含中文；使用表格 ID + 英文名稱 + 序號，例如 `FX-01_dash_boost_001` | 若採序列圖，檔名需依播放順序編號。 |
| 音樂 / 音效 | WAV 或 OGG | 使用表格 ID，例如 `SFX-07_Dash_Start` | 需可循環者在備註標明 Loop。 |
