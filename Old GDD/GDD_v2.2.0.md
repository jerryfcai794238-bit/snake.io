# Snake.io 遊戲設計文件 (GDD) v2.2.0 - 長度博弈與節奏優化版

## 變更日誌 (Changelog)
- **核心機制**：DASH 從消耗能量改為消耗「自身長度」。
- **生存規則**：取消「一命制」，改為「3 秒復活制」。
- **勝負判定**：從比拼當前長度改為比拼「總累計進食量 (Score)」。
- **視覺優化**：地圖物件密度降低 30%，石頭強化紅框邊界，食物統一黃色大小分級。
- **對應版本**：由 `v2.1.3` 演進而來。

---

## 1. 遊戲顯示與 UI 規格

### 1.1 基本規格
- **解析度**：固定手機直屏 **1080 * 1920 (9:16)**。
- **地圖規模**：小型競技地圖，物件總量降低 30% 以提升新手友善度。

### 1.2 HUD 與視覺反饋
- **HUD 元素**：
  - **頂部資訊**：左側顯示「目前長度 (Length)」，右側顯示「總分 (Score/Total Eaten)」。
  - **復活提示**：死亡後中心顯示 3 秒倒數計時。
- **視覺反饋 (VFX)**：
  - **進食**：黃色粒子擴散特效。
  - **石頭**：高亮**紅色邊框**（與地圖邊界一致），內部炭灰色。
  - **食物**：統一**黃色** (#FFD700)，依數值分為三種大小。

---

## 2. 操作系統 (Controls)

### 2.1 DASH 規則 (核心變更)
- **消耗機制**：每秒消耗 **40 單位** 長度。
- **最低門檻**：長度低於 **50** (初始長度) 時無法 DASH。
- **加速倍率**：1.5 倍基礎速度。

---

## 3. 遊戲規則

### 3.1 死亡與復活
- **復活機制**：死亡後 3 秒在安全區域復活，初始長度重置為 50。
- **死亡損失**：死亡不影響總分 (Score)，但會損失當前長度進度。

### 3.2 恢復機制
- **緊急恢復**：若因被截斷或 DASH 消耗導致長度低於 50，吃下**任意**一顆食物後，長度立即恢復至 50。

---

## 4. 資源生成邏輯

### 4.1 食物分級
- **Small (2)**：地圖隨機分佈，提供基礎成長。
- **Medium (5)**：河流、冰原等地形區分佈。
- **Large (10)**：石頭邊緣、中心高壓區分佈。

### 4.2 移除項目
- **能量球 (Energy Orbs)**：已移除，所有加速均依賴自身長度。
