# Snake.io 遊戲設計文件 (GDD) v2.1.0 - 核心對抗重塑版

## 1. 遊戲核心目標

本遊戲旨在將傳統的貪食蛇玩法轉化為高壓、精確且具備格鬥感的對抗體驗。強調空間博弈、資源爭奪與瞬間截斷的爽快感。

---

## 2. 遊戲模式定義

### 2.1 [SOLO] 個人挑戰

- **目標**：單人模式。在限定時間內（如 90 秒），挑戰在不死的情況下獲得最大長度。
- **策略重點**：效率極大化、資源收割路徑規劃。
- **遊玩情境範例**：
  - **範例 A：高密度收割 (Density Harvesting)**
    - 玩家在開闊地發現一塊食物密集生成的「高壓區」。玩家發動 **DASH** 快速進入該區域，在食物消散前，以高速劃過最密集的路徑，極大化單次充能收益。
  - **範例 B：河流能量儲備**
    - 玩家刻意進入河流（減速區）邊緣。雖然速度降低，但此處生成的能量球密度較高。玩家在此緩速收集能量，為之後的爆發做準備。
  - **範例 C：冰面滑行操控 (Ice-Slide Mastery)**
    - 冰面會降低摩擦力並產生慣性。玩家在冰面區域利用 **DASH** 提供的瞬間推力來強行「修正方向」或「快速脫離」打滑區域，確保精確拾取高價值食物。

### 2.2 [1v1 Duel] 雙人對抗

- **目標**：使對手死亡，或在時間結束時長度領先。
- **核心機制**：**DASH 截斷機制**。
  - 在 DASH 狀態下撞擊對手身體（含側面與追尾），可將對手截斷。
  - 被截斷部分化為食物。對手不會死亡，帶著剩餘前段繼續戰鬥。
- **遊玩情境範例**：
  - **範例 A：絕地反殺 (Tail-gate Cut)**
    - 對手長度領先並試圖圍堵玩家。玩家在對手轉向受限的瞬間，發動 **DASH 追尾撞擊** 截斷對手的蛇身，扭轉局勢。
  - **範例 B：河流陷阱戰術**
    - 玩家誘導對手進入河流（減速區）。玩家在河岸（正常速區）發動 **DASH** 快速切入，利用速度差精確截斷對手。
  - **範例 C：資源點壓制 (Resource Pinning)**
    - 對手正在大石頭旁邊吞食「大型食物」。由於對手一側是致命石頭，轉向空間受限，玩家發動 **DASH** 從外側封鎖逃生路徑並進行截斷。

## 3. 戰鬥與碰撞規則

### 3.1 死亡判定

| 判定類型 | 內容描述 | 結果 |
| :--- | :--- | :--- |
| **撞擊敵身** | 蛇頭觸碰到敵蛇身體（非 DASH 狀態）。 | **死亡** |
| **邊界撞擊** | 蛇頭觸碰到地圖邊緣。 | **死亡** |
| **障礙物撞擊** | 蛇頭觸碰到牆壁、石頭等場景障礙。 | **死亡** |
| **頭對頭** | 兩蛇正面相撞。 | **長度短者死** |
| **撞擊己身** | 蛇頭觸碰到自己的蛇身。 | **無效 (可穿過)** |

### 3.2 DASH (衝刺) 系統

- **功能**：提升移動速度，並開啟「截斷」攻擊判定。
- **充能**：拾取場地上的「能量點」為能量槽充能。
- **限制**：DASH 無法穿透障礙物與牆壁。

## 4. 場景與地形設計

### 4.1 致命障礙物

- **外牆 (Walls)**：地圖邊界，不可觸碰。
- **石頭 (Stones)**：散佈於地圖中的靜態障礙物。大小不一，撞擊即死。

### 4.2 特殊地形

- **河流 (River)**：進入後移動速度**降低 25%**。通常是能量點的密集生成區。
- **冰面 (Ice)**：進入後摩擦力降低，轉向帶有慣性，操控難度提升。

---

## 5. 資源生成邏輯 (Spawning Logic)

### 5.1 食物 (Food)

- **基礎分佈**：全地圖隨機生成小型食物。
- **鄰近權重生成**：以**牆壁**與**石頭**為中心。
  - **0-50 像素內**：高機率生成大型食物 (Large)。
  - **50-150 像素內**：生成中型食物 (Medium)。
  - **設計意圖**：引誘玩家在致命障礙物邊緣進行高難度操作以換取高回報。

### 5.2 能量 (Energy)

- **戰略投放**：能量點主要分佈於河流中心、石頭窄縫或冰面末端。
- **設計意圖**：要求玩家利用地形操作或 DASH 才能獲取，強調戰略重要性。
