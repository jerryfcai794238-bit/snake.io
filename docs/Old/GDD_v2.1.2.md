## 1. 遊戲模式定義

### 2.1 [SOLO] 個人挑戰
- **目標 (Goal)**：在 90 秒內不死亡的情況下，獲取最大蛇身長度。
- **核心策略 (Core Strategy)**：**「高效率資源掠奪」**。
- **手段 (Means)**：
  - **區域衝刺 (Zone Sprint)**：利用 DASH 快速跨越資源稀疏區。
  - **地形補償 (Terrain Compensation)**：利用 DASH 抵銷河流減速或在冰面修正方向。
- **情境範例**：包含高密度收割、河流能量儲備、冰面慣性修正。

### 2.2 [1v1 Duel] 雙人對抗
- **目標 (Goal)**：在時間結束前擊殺對手，或使自己的長度領先對手。
- **核心策略 (Core Strategy)**：**「空間壓迫與精確截斷」**。
- **手段 (Means)**：
  - **DASH 截斷**：在對手靈活性受限時，發動衝刺撞擊其身體（含追尾）。
  - **資源卡位**：利用「己身可穿透、敵方不可穿透」特性封鎖路徑。
- **情境範例**：包含絕地反殺、河流陷阱、資源點壓制。

## 2. DASH (衝刺) 系統技術規格

### 2.1 性能與消耗
- **速度加成 (Speed Bonus)**：提升至基礎速度的 **150% (1.5倍速)**。
- **消耗速率 (Consumption Rate)**：
  - 持續按壓時，每秒消耗能量槽總量的 **33.3%**。
  - **最大持續時間**：能量槽 100% 時可連續衝刺 **3 秒**。
- **啟動門檻 (Startup Threshold)**：能量槽必須至少有 **10%** 的剩餘能量始可發動 DASH。

### 2.2 充能規則 (Charging Rules)
- **能量球補給**：每拾取一顆能量球，立即恢復能量槽總量的 **20%** (拾取 5 顆即可填滿)。
- **限制**：能量不會隨時間自動恢復。
- **截斷獎勵**：1v1 中成功截斷對手後，原地額外噴發 2 顆能量球。

## 3. 戰鬥與碰撞規則

### 3.1 死亡判定
| 判定類型 | 內容描述 | 結果 |
| :--- | :--- | :--- |
| **撞擊敵身** | 蛇頭觸碰到敵蛇身體（非 DASH 狀態）。 | **死亡** |
| **邊界撞擊** | 蛇頭觸碰到地圖外緣。 | **死亡** |
| **障礙物撞擊** | 蛇頭觸碰到牆壁、石頭等場景障礙。 | **死亡** |
| **頭對頭** | 兩蛇正面相撞。 | **長度短者死** |
| **撞擊己身** | 蛇頭觸碰到自己的蛇身。 | **無效 (可穿過)** |

## 4. 場景與資源生成

### 4.1 場景障礙
- **石頭 (Stones)**：全地圖分佈的大小障礙，碰撞即死，資源生成錨點。
- **河流/冰面**：負面地形（減速 25%/慣性慣性）。

### 4.2 生成邏輯
- **食物**：以牆、石為中心，鄰近區域 (0-50px) 產出大型食物。
- **能量**：主要分佈於地形複雜區（河流中心、石頭窄縫）。
