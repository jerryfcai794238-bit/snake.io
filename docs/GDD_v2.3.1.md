# Snake.io 遊戲設計文件 (GDD) v2.3.1 - 競技對決與動態平衡版

## 變更日誌 (Changelog)
- **死亡掉落強化**：死亡後屍體轉化為 **80%** 的食物能量，但僅存在 **5 秒**，超時自動消失。
- **DASH 動態平衡**：
    - **累進消耗**：公式 `40 * (1 + (長度-50)/250)`。
    - **尾部掉落**：衝刺消耗長度的 **60%** 會掉落在蛇尾。
- **重生優化**：復活時自動朝向環境最空曠（遠離牆壁與石頭）的方向。
- **競技數據**：新增 `CUTS` (截斷) 獨立統計，優化結算頁面為雙方對比表格。
- **勝負判定**：以 **Total Score (累積進食量)** 決定勝負。

## 1. 核心機制 (Core Mechanics)

### 1.1 DASH 規則
- **消耗與回饋**：
    - 基礎消耗：40 單位/秒。
    - 累進系數：長度每增加 250，消耗速度翻倍。
    - 資源回收：消耗量的 60% 會掉落。
- **限制**：長度低於 50 時無法使用 DASH。

#### DASH 消耗對照表 (動態遞減計算)
| 目前長度 | 消耗速率 (u/s) | 可衝刺總時長 | 備註 |
| :--- | :--- | :--- | :--- |
| **50** | 40 | 0s | 初始長度不可衝刺 |
| **100** | 48 | ~1.1s | 消耗率隨長度下降而減緩 |
| **200** | 64 | ~2.9s | 適合短距離突襲 |
| **300** | 80 | ~4.3s | 長度達 300 時消耗率翻倍 |
| **500** | 112 | ~6.4s | 資源消耗極快 |
| **1000** | 192 | ~9.4s | 長度優勢轉換為爆發時長 |

### 1.2 死亡與資源循環
- **屍體價值**：死亡後 80% 的長度轉換為食物。
- **時效性**：屍體轉換的食物具備 **5 秒生存時間**，旨在誘導玩家進行高風險的高速搶食。

## 2. 環境與地形 (Environment)

### 2.1 地圖物件
- **石頭**：炭灰色，帶有紅色警示邊框。
- **冰面**：面積縮減 20%，提供低轉向靈敏度的滑行體驗。
- **河流**：提供 0.75x 的移動減速。

### 2.2 食物分級 (Yellow Only)
- **Small (2)** / **Medium (5)** / **Large (10)**。
- 死亡掉落物與 DASH 掉落物亦遵循此價值體系。

## 3. 競技數據與 UI

### 3.1 結算指標 (Settlement Stats)
1.  **TOTAL SCORE** (勝負主標)
2.  **KILLS** (頭部碰撞擊殺)
3.  **CUTS** (衝刺截斷次數)
4.  **DEATHS** (死亡次數)
5.  **MAX LENGTH** (最高長度)
6.  **DASH TIME** (累計衝刺秒數)

### 3.2 視覺反饋
- **勝利 (VICTORY)**：金色標題。
- **失敗 (DEFEAT)**：粉色標題。
- **優勢數據**：表格中使用金色發光方框高亮。
