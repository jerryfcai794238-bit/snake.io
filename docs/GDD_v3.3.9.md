# Snake.io - Combat Evolved (v3.3.9)
## 遊戲設計文檔 (GDD)

### 1. 核心定位
*   **競技橫屏**：專為 1920x1080 橫屏環境設計。
*   **MOBA 操控**：左搖桿 (移動) + 右側技能群 (1 Dash + 3 Skills)。

### 2. 操控與介面 (UI/UX)
*   **快捷鍵佈局 (Keyboard)**：
    *   **`1`**：加速 (Dash / Rocket)。
    *   **`2`**：磁鐵 (Magnet)。
    *   **`3`**：噴墨 (Ink Cloud)。
    *   **`4`**：鷹眼 (Eagle Eye)。
*   **技能 HUD (Head-up Display)**：
    *   當磁鐵、鷹眼或致盲啟動時，蛇頭上方會顯示圖標與紅色倒數進度條。
    *   **🌑 (致盲圖標)**：當蛇踩到噴墨時顯示。

### 3. 技能系統 (v3.3.9)
*   **1. 體力制加速衝刺 (Dash)**
    *   消耗體力，具備過熱 (Overload) 機制。
*   **2. 鷹眼 (Eagle Eye)**
    *   **冷卻**：25 秒。
    *   **持續**：12 秒。
    *   **效果**：視野平滑擴張 (Lerp Zoom Out)。
*   **3. 噴墨煙霧 (Ink Cloud)**
    *   **冷卻**：20 秒。
    *   **釋放點**：蛇頭中心 (Head Drop)。
    *   **屬性**：自我免疫。
    *   **對 AI 影響 (v3.3.9)**：AI 視野縮減至 100px (原 400px)，且行進方向會隨機偏移 (亂竄)。
    *   **視覺**：半徑 60px。玩家墨水為高飽和電光紫帶發光；AI 為深紫色。
*   **4. 磁鐵 (Magnet)**
    *   **冷卻**：30 秒。
    *   **效果**：吸取周邊食物。

### 4. 戰鬥反饋
*   **受傷反饋**：蛇身紅白閃爍 (Body Flashing)。
*   **致盲反饋**：玩家產生黑化暈影；AI 顯示 🌑 圖標並失去導航精度。

### 5. 版本更新摘要 (v3.3.9)
*   **核心改進**：實作 AI 致盲機制，讓噴墨對電腦對手產生實質戰術干擾。
*   **視覺反饋**：新增蛇頭上方致盲圖標 HUD。
