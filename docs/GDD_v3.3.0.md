# Snake.io - Combat Evolved (v3.3.0)
## 遊戲設計文檔 (GDD)

### 1. 核心定位
*   **競技橫屏**：專為 1920x1080 橫屏環境設計，適配 PC 與高解析度手機 (如 iPhone 14)。
*   **MOBA 操控**：採用左搖桿、右技能佈局，強化即時反應與戰術深度。

### 2. 操控與介面 (UI/UX)
*   **佈局 (Landscape)**：
    *   **左側**：虛擬搖桿 (Joystick)。
    *   **右下角**：MOBA 戰鬥按鈕群。
        *   **主按鈕 (Dash)**：體力制加速。
        *   **副按鈕 1 (Eagle Eye)**：視野擴張 (Q)。
        *   **副按鈕 2 (Ink Cloud)**：噴墨干擾 (E)。
        *   **副按鈕 3 (Magnet)**：磁鐵 (F)。

### 3. 技能系統
*   **1. 體力制加速衝刺 (Dash)**
    *   **資源**：Stamina (100)，每秒耗 33.3，回滿需 15 秒。
    *   **特性**：過熱鎖定，加速期間進食不補體力。
*   **2. 鷹眼 (Eagle Eye)**
    *   **消耗**：20 Stamina / CD 20秒。
    *   **效果**：視野擴張 1.5 ~ 2 倍，持續 8 秒。
*   **3. 噴墨煙霧 (Ink Cloud)**
    *   **消耗**：30 Stamina / CD 20秒。
    *   **效果**：在尾部留下黑煙，踩到的對手會「致盲」3 秒（視野縮小，四周變黑）。
*   **4. 磁鐵 (Magnet)**
    *   **CD 30秒**：吸取周邊食物。

### 4. 戰鬥機制與平衡
*   **死亡繼承**：繼承當前長度 50%。
*   **切斷機制**：加速狀態可截斷對手。
*   **地形互動**：撞牆/石回彈並**扣除 15% 長度**。
*   **視覺反饋**：受傷紅光、尾部碎裂 (Shatter) 特效。

### 5. 環境與資源
*   **地圖規模**：2000 x 2000 px，7 個 AI。
*   **食物規則**：800/400 總量管控，空曠區 50% 分布。

### 6. 技術更新日誌 (v3.3.0)
*   **新增技能：鷹眼 (Eagle Eye)**。
*   **新增技能：噴墨煙霧 (Ink Cloud)**。

*   **碎裂特效優化**：調整 TAIL_SHATTER 停滯與逐段消逝邏輯 (v3.2.5)。
