# 動物滑塊 衛星 APP (sa-framework) 企劃規格書

**文件版本**：1.3
**更新日期**：2026-05-19
**適用框架**：`sa-framework`

---
## 1. 專案概述

本文件定義將《動物滑塊》從「玩星派對平台」移植為「獨立衛星 APP」的各項企劃規格。
核心目標為**去平台化**與**本地經濟重構**。遊戲將全面移除平台綁定的能量、成長與收集系統，改為「單一金幣貨幣制」加上「帶有使用上限的道具系統」，並深度整合 `sa-framework` 的內建標準活動與廣告模組（AdModule、ActivityServiceProvider）來達成商業化變現。

---
## 2. 系統刪減與保留清單

為符合獨立 APP 的輕量化與單機體驗，針對原版《動物滑塊》進行以下系統增刪：

### 🛑 必須移除的系統 (Remove)
*   **成長之路**：移除對應介面與相關進度累計。
*   **十連勝系統**：移除連勝 UI 與額外獎勵機制。
*   **收集系統**：移除碎片收集與圖鑑系統。

### ✅ 必須新增/修改的系統 (Add / Modify)
*   **貨幣系統**：金幣、能量。
*   **道具系統**：原版的技能，改為「單局次數限制」的消耗型道具。
*   **sa-framework 系統模組接入**：
    *   接入 `ActivityServiceProvider`（每日簽到、幸運轉盤）。
    *   接入 `AdModule`（橫幅廣告、獎勵廣告）。
    *   接入 `CrossPromotion`（衛星互導按鈕）。
    *   接入 `UserSystem` 與 `InAppPurchase`（去廣告、購買金幣及能量）。

## 3. 遊戲經濟與機制重構

### 3.1 經濟體系：金幣與能量
遊戲內導入「金幣」作為主要的流通貨幣，並引入「能量」作為限制遊玩次數的機制。

#### 金幣 (Coins)
*   **獲取途徑**：
    1. **模式**：
        1. **過關模式**：過關獲得金幣。
        2. **挑戰模式**：依分數獲得金幣（可設定級距 e.g. 5000分3000金幣、10000分5000金幣）。
    2.  **活動服務 (sa-framework)**：透過每日簽到、幸運轉盤、獎勵廣告獲得。
    3.  **商城內購**：付費購買金幣包。
*   **消耗途徑**：
    1.  **接關 (Revive)**：單局失敗時，可支付金幣接關（或看廣告）。
    2.  **購買道具 (Items)**：單局內購買消耗性道具。

#### 能量 (Energy)
玩家每次進入遊戲關卡時皆會消耗能量。
*   **消耗**：每次點擊 PLAY 進入關卡扣除 20(關卡) / 30(挑戰) 點能量。(和玩星相同)
*   **獲取與恢復**：
    1.  **隨時間恢復**：每六分鐘恢復一點，直到達到自然恢復上限300 (和玩星相同)
    2.  **看廣告補充**：能量不足時或主動點擊，可觀看獎勵廣告恢復能量。
    3.  **商城內購**：付費購買能量。

### 3.2 商城機制
獨立 APP 需要建立完整的付費機制，接入 `sa-framework` 的支付模組。

1.  **購買金幣與能量**：設定多個金幣與能量的定價檔位 (例如：$0.99 買 1000 金幣、$0.99 買能量包)。
2.  **去廣告 (Remove Ads)**：一次性買斷商品。購買後，大廳的 Banner 廣告以及結算返回大廳的插頁廣告將被永久關閉（**注意**：玩家主動點擊的「獎勵廣告」如接關、雙倍、買道具等，仍需保留給玩家使用，但可以不用看廣告就獲得該好處）。

### 3.3 道具系統 (原主動技能改制)
將原版玩星中的**「主動技能」完整轉換為「單局次數限制」的消耗型道具**。其功能與原版完全相同，但玩家必須在局內花費金幣購買，或透過看廣告取得單次使用權。

| 道具名稱 (原主動技) | 效果說明 | 單局使用上限 | 獲取方式 |
| :--- | :--- | :---: | :--- |
| **切割方塊** | 將畫面上較大的動物方塊切碎，幫助盤面掉落與重組。 | 9 次 | 消耗金幣 / 獎勵廣告 |
| **破解障礙** | 清除或破解盤面上的冰凍、鎖定等障礙方塊狀態。 | 9 次 | 消耗金幣 / 獎勵廣告 |
| **瞬間爆氣** | 使用後立即將局內的「必殺技能量條」集滿，可直接發動必殺技。 | 9 次 | 消耗金幣 / 獎勵廣告 |

*(註：原版中的被動技皆移除，但原版靠消除方塊累積能量的「必殺技系統」將完整保留於局內)*

### 3.4 進度解鎖機制
1.  **獲得 Skin**：隨關卡進度解鎖不同的動物方塊外觀 (例: 關卡6 獲得 Skin 2)。
2.  **獲得 必殺技**：隨關卡進度解鎖不同的必殺技 (例: 關卡30 獲得 必殺技 2)。
3. 獲得以上獎勵時，跳出獲得獎勵彈窗 (參考5.13條目)
