# Workflow: Generate Presentation 簡報製作與自動生成規範

本工作流規範如何根據最新規格與反饋，生成高品質的項目提案簡報 `.pptx`。

---

## 📌 1. 必備前置參考資料
在製作或修改簡報前，必須詳閱並同步以下專案文件，以確保內容完全吻合：
1. **當前最新 GDD 規格書 (如 `GDD_v5.0.0.md`)**：
   * 確保簡報中的遊戲玩法、核心主動技能（衝刺、磁力漩渦）、地圖道具（磁鐵、巨大蘑菇、幸運 7）與局外養成（科技樹、成長之路）之規格、公式與數值完全一致。
2. **最新簡報大綱 (如 `presentation_v5.2.0/提案簡報大綱.md`)**：
   * 確保投影片頁碼、主題分配（例如核心玩法、6+6選品策略、美術風格）以及結構層級正確。
3. **最新簡報反饋 (如 `presentation_v5.2.0/提案簡報反饋.txt`)**：
   * 注意上一輪會議對簡報細部版面、圖文簡化或結構順序的具體調整指示。

---

## 🎨 2. 全域設計規範 (任天堂活力專業風)
* **主色配比 (60-30-10)**：珍珠白背景 (`#F8F9FA`)、深灰字體 (`#2B2D42`)，並以任天堂紅 (`#E60012` 衝刺/對抗)、耀西綠 (`#3CD070` 模式/優勢)、金幣黃 (`#FFD000` 道具/金流) 作為焦點標示。
* **排版**：採用卡片式排版、圓角 Pill Badges 標籤與左右分欄（一側說明，另一側影片/插圖展示）。

---

## 💻 3. PPTX 簡報產出雙軌路徑

本專案提供兩種自動化產生 PPTX 簡報的方式，均放置在 `presentation_v5.2.0/tools/`：

### 路徑 A：代碼原生繪製嵌入法 (精緻原生 PPTX)
此路徑使用 API 直接繪製投影片卡片，並將 `.mp4` 影片及 JPG/PNG 素材原生嵌入簡報中。簡報文字均可在 PowerPoint 內二次編輯。

* **適用場景**：需要產出能隨時手動編輯修改文字、且能在簡報內直接播放實機 Demo 影片的原生簡報。
* **使用腳本**：`presentation_v5.2.0/tools/generate_pptx.js`
* **執行指令**：
  ```bash
  node presentation_v5.2.0/tools/generate_pptx.js
  ```
* **產出檔案**：根目錄下的 `Snake.io_競技場_提案簡報.pptx` (會包含嵌入的 Mp4 影片，約 98MB)。

---

### 路徑 B：HTML 網頁截圖打包法 (高保真特效 PPTX)
此路徑先以 HTML 簡報作為基礎，再透過 Puppeteer 啟動無頭瀏覽器，對每一頁網頁進行 2x 高解析度截圖，最後封裝為 PPTX。

* **適用場景**：需要百分之百還原 HTML 簡報上華麗的 CSS/JS 動態版面、漸層色與邊框，且不需要在 PPTX 內直接播放影片的展示場合。
* **使用腳本**：`presentation_v5.2.0/tools/capture-presentation.js`（依賴網頁 `presentation_v5.2.0/index.html`）
* **執行指令**：
  ```bash
  node presentation_v5.2.0/tools/capture-presentation.js
  ```
* **產出檔案**：`presentation_v5.2.0/Snake.io_競技場_提案簡報_v5.2.0.pptx` (將每頁渲染為靜態圖片，約 98MB)。

---

## 🛠️ 4. 依賴與驗證
* 確保安裝 `npm install` 所需依賴，包含 `pptxgenjs` 與 `puppeteer`。
* 執行生成後，需打開簡報檢查：
  1. 圖片/影片載入是否正常。
  2. 文字內容是否有中文亂碼或重疊排版。
