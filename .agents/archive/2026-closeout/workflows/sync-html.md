# Workflow: Sync HTML 簡報製作與同步規範

此工作流規範如何將「提案簡報大綱.md」及「內部會反饋」轉化為高品質的 HTML/CSS/JS 3D 動態簡報。

## 📌 核心來源與前置作業
- **來源大綱**：最新版 `提案簡報大綱.md`。
- **參考反饋**：`提案簡報_內部會反饋.txt` 中的細節修正（如圖片佈局、金流回收簡化等）。
- **圖片資源**：確認新版本簡報資料夾內包含所需插圖（如 `images/Dada_TechTree.jpg` 及 `images/瑪利歐*` 參考圖）。

---

## 🎨 全域視覺設計系統規範 (Nintendo-Style Playful Professional)
在編寫 HTML 簡報時，必須嚴格遵守以下視覺規範：
1. **全域色彩配比 (60-30-10 原則)**：
   - **60% 背景**：珍珠白/淡灰 (`#F8F9FA` / `#F1F3F5`)，避免刺眼純白。
   - **30% 輔助/正文**：石板灰 (`#495057` 正文字體)；卡片底色使用 `white` 或淡藍色 (`#E8F0FE`)。
   - **10% 品牌焦點 (Accent)**：
     - **任天堂紅 (`#E60012`)**：標示核心對抗、衝刺、擊殺與重要標題。
     - **耀西綠 (`#3CD070`)**：標示模式、正向成長與優勢。
     - **金幣黃 (`#FFD000`)**：標示金幣消耗、進化與道具。
2. **版面元件**：
   - **Switch 卡片**：圓角限用 `border-radius: 20px`，並搭配微弱 3D 陰影。
   - **藥丸標籤**：使用圓角 Pill Badges（如 `badge-red`, `badge-green`）突顯條列資訊。
3. **字體**：標題使用圓潤厚實字型（如 *Fredoka* 或 *Outfit*），正文使用幾何無襯線體（如 *Inter* 或 *Roboto*）。

## 📐 19 頁結構與頁面排版細則
簡報結構共計 19 頁，必須按順序嚴格實作：

### 1. 封面 (Page 01)
- **視覺**：亮紅色背景、Joy-Con 雙色撞色圓角點綴。

### 2. 核心前導頁 (Page 02)
- **規則**：**嚴禁裝飾插圖**。
- **內容**：置中排列核心組合三詞公式（`多人亂鬥 X 體力控管 X 截斷反殺`），下方設置三個競品（Snake.io、Snake Clash、Snake Merge）的外顯連結按鈕。

### 3. 簡報大綱 (Page 03)
- **規則**：**嚴禁裝飾插圖**。
- **內容**：依序條列七大主題與第八點 Q&A。

### 4. 段落過渡頁 (Page 04, 07, 09, 11, 13, 15, 17)
- **規則**：主題間的分割頁。
- **視覺**：簡約珍珠白背景，中央亮紅色單行粗體大字。

### 5. 核心玩法 (Page 05 & 06)
- **頁碼標記**：第一頁標記 `(1/2)`，第二頁標記 `(2/2)`。
- **Page 05 (1/2)**：介紹基本雙鍵操作與疲勞超載（Overload）。下方保留本款遊戲實機截圖展示區。
- **Page 06 (2/2)**：介紹 Solo、大亂鬥、團體賽三大模式。並排展示簡易碰撞規則表。

### 6. 6+6 選品策略 (Page 08)
- **頁碼標記**：單頁標記 `(1/1)`。
- **視覺**：左右雙卡片對照（左邊 3 大成功策略，右邊 3 大心理驅動實際落實）。

### 7. 參考競品資訊 (Page 10)
- **內容**：將加減法定位分析直接寫在各自競品（Snake.io、Snake Clash、Snake Merge）的介紹卡片中。
- **佈局**：左側為三個競品對照卡片；右側為競品 App Icon 三聯圖；下方預留對抗展示影片播放區。

### 8. 技能與道具設計 (Page 12)
- **排版**：**上 2 下 3 佈局**。
  - **上半部**：兩個主動技能卡片（Dash 衝刺與磁力漩渦）。
  - **下半部**：三個地圖道具卡片（磁鐵、巨大蘑菇、幸運 7）。

### 9. 成長之路結合 (Page 14)
- **規則**：**嚴禁無用裝飾插圖**。
- **內容**：使用「玩星派對」風格之線性星等里程碑養成（20★），以進度節點圖直觀呈現。

### 10. 金流回收方式 (Page 16)
- **內容**：戰前金幣被動 Perks 啟用（單局消耗）+ 噠噠特攻式進化科技樹（永久屬性）。
- **視覺**：左側說明文字，右側引入 `images/Dada_TechTree.jpg` 科技樹插圖。

### 11. 美術視覺介紹 (Page 18) (倒數第二頁)
- **內容**：只寫美術定調說明，不寫核心美術與爽感細節。
- **視覺**：左側定調文字，右側/下方展示《瑪利歐網球》、《瑪利歐派對》、《瑪利歐賽車8》參考圖片的並列畫廊（視版面擁擠度可選用 2~4 張，放不下時精簡為 2 張）。

### 12. Q&A (Page 19) (最後一頁)
- **規則**：**嚴禁內容文字與裝飾插圖**。
- **視覺**：簡約珍珠白背景，置中顯示大標 `Q&A`。

## 💻 技術框架與控制邏輯 (JS/CSS)
1. **投影片切換變數**：在 JS 中，將 `totalSlides` 設定為 `19`。
2. **3D 切換效果**：使用 CSS `.slide-container.active` 與 `.slide-container.prev-active` 控制 3D 翻轉與淡入淡出。
3. **導航指示器**：初始化並生成對應的 19 個 Dots。
4. **圖片防呆 (Fallback)**：所有圖像標籤必須加入 `onerror="this.style.display='none'"` 屬性，確保在圖片遺失時排版不崩潰。
5. **鍵盤與全螢幕**：
   - 支援 `ArrowRight` / `Space` / `Enter` 切換下一頁；`ArrowLeft` / `Backspace` 返回上一頁。
   - 實作全螢幕 API (`toggleFullscreen()`)，在 `:fullscreen` 模式下移除邊框限制以滿版展示。
