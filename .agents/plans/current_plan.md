# Current Implementation Plan

## 任務

檢查並修正 `GDD/貪食蛇GDD.md` 中 Reference Image 插圖沒有成功接入的問題。

## 影響範圍

- 修改檔案：`GDD/貪食蛇GDD.md`
- 參考來源：`GDD/Reference Image/`
- 不修改圖片檔。
- 不修改程式碼。

## 將讀取的檔案

- `GDD/貪食蛇GDD.md`
- `GDD/Reference Image/` 內目前存在的圖片

## 將修改的檔案

- `GDD/貪食蛇GDD.md`

## 備份策略

- 修改前備份原檔到 `scratch/backups/YYYYMMDD_HHMMSS/GDD/貪食蛇GDD.md`。

## 執行步驟

1. 列出 `GDD/Reference Image/` 目前所有圖片。
2. 找出 GDD 內所有 Markdown 圖片語法。
3. 檢查圖片路徑是否能從 `GDD/貪食蛇GDD.md` 正確解析到實際檔案。
4. 找出仍未替換的字元圖區塊。
5. 建立缺漏清單：
   - 圖片存在但未被 GDD 引用
   - GDD 引用路徑錯誤
   - 應替換但仍是字元圖
6. 備份 GDD。
7. 修正 Markdown 圖片路徑與缺漏插入/替換。
8. 讀回相關章節驗證。
9. 回報修正摘要、備份位置與仍需人工確認的項目。

## 預期修正方向

- 優先使用 Markdown 相對路徑，必要時改用角括號處理空白路徑：
  `![說明](<Reference Image/檔名.png>)`
- 將仍有對應圖片的字元圖替換為圖片。
- 不確定用途的圖片不強插。

## 驗證方式

- GDD 內每個圖片連結都能對應到實際存在的檔案。
- Reference Image 中有明確章節對應的圖片都被引用。
- 對應章節不再保留應被替換的字元圖。
- 不修改圖片檔或程式碼。

## 不做的事

- 不刪除圖片。
- 不重新命名圖片。
- 不修改程式碼。
- 不處理無法明確判斷用途的圖片，除非可從檔名和章節明確推斷。

## 等待確認

請使用者回覆「確認」或「開始」後再執行。
