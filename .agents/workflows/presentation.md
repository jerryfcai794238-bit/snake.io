# Workflow: Presentation

## 真源

- 遊戲規格：`GDD/貪食蛇GDD.md`。
- 簡報結構：`presentation_v5.2.0/提案簡報大綱.md`。
- 修正需求：`presentation_v5.2.0/提案簡報反饋.txt`。
- 現有視覺、媒體與生成腳本：`presentation_v5.2.0/`。

大綱與反饋決定頁數、順序和內容；workflow 不重複保存逐頁規格。

## 執行流程

1. 唯讀比對 GDD、大綱、反饋、HTML、媒體與目前 PPTX。
2. 在 Plan 中列出要更新的頁面、來源、輸出路徑、備份與驗證；等待「開始」。
3. 備份本次會修改的簡報來源與輸出。
4. 更新 HTML／CSS／JS 或目前對應的 PPTX 生成腳本，不順手重構其他工具。
5. 依需求選擇：
   - 原生 PPTX：文字與媒體可編輯。
   - HTML 截圖 PPTX：優先保持網頁視覺。
6. 生成後檢查頁數、中文、字型、重疊、裁切、圖片／影片、鍵盤與全螢幕操作。

## 限制

- 不從舊版輸出檔反推規格。
- 不硬編版本號或輸出檔名；先檢查現有工具與當前目標版本。
- 未明確要求推版時，不更新 GDD 或版本紀錄。
